## 🛠️ Global Development Standards

- **Filesystem Hygiene**: Clean repository structure without unchecked node_modules, build artifacts, or local test logs.
- **Security First**: All private credentials, API keys, and environment variables are strictly abstracted through `.env.example` templates.
- **Zero Crude Primitives**: High-fidelity 3D assets, PBR materials, and real-time physical rendering across all Godot and Unity projects.
